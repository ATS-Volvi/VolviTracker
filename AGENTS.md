# Repository Guidelines & Behavioral Rules

## Strictly Prohibit Demo Profiles
- **Never add demo profiles, demo accounts, or demo sign-in options**:
  Under no circumstances should demo profiles, quick demo sign-in buttons, preset accounts, or one-click demo login switchers be added to the UI (including the Login page, Sidebar, or Navbar), even if a new role is introduced to the application.
- All users must authenticate through the standard login flow with their registered credentials or sign up directly.
